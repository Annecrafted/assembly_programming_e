# README - 06.asm

```asm
mov eax, 0x11223344
mov ebx, 0x1234
```

loads the values `0x11223344` and `0x1234` into `EAX` and `EBX` respectively. These instructions do not use the stack, so `ESP` does not change.

```asm
push eax
```

pushes the value stored in `EAX` onto the stack. Since this is a 32-bit program, `ESP` decreases by 4 bytes.

```asm
push ebx
```

pushes the value stored in `EBX` onto the stack. `ESP` decreases by another 4 bytes.

At this point, the stack contained:

```text
Top
0x1234
0x11223344
Bottom
```

```asm
nop
```

does not perform any operation and does not affect the stack or register values.

```asm
pop ebx
```

removes the value `0x1234` from the top of the stack and stores it in `EBX`. `ESP` increases by 4 bytes.

```asm
pop eax
```

removes the value `0x11223344` from the stack and stores it in `EAX`. `ESP` increases by another 4 bytes and returns to its original value.

## Observations

- `push eax` decreased `ESP` by 4 bytes.
- `push ebx` decreased `ESP` by another 4 bytes.
- `pop ebx` increased `ESP` by 4 bytes.
- `pop eax` increased `ESP` by another 4 bytes.
- The last value pushed onto the stack (`0x1234`) was the first value removed.
- The stack follows the Last In First Out (LIFO) principle.
- After both `POP` instructions executed, `ESP` returned to its original value.
- The stack was used to temporarily store the values held in `EAX` and `EBX`.
