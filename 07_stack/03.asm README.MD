# README - 03.asm

```asm
mov rax, 10
```

loads the value 10 into `RAX`. This instruction does not use the stack, so `RSP` does not change.

```asm
call calculate
```

calls the `calculate` function. During testing in GDB, I observed that `RSP` decreased by 8 bytes. This happened because the return address was pushed onto the stack before the function was called.

```asm
add rax, 5
```

adds 5 to the value stored in `RAX`, changing it from 10 to 15. This instruction does not affect the stack.

```asm
ret
```

removes the return address from the stack and returns execution to the instruction after the function call. I observed that `RSP` increased by 8 bytes and returned to its original value.

```asm
nop
```

does not affect the stack or any register values.

## Observations

- `call calculate` decreased `RSP` by 8 bytes.
- `ret` increased `RSP` by 8 bytes.
- No values were manually pushed onto the stack.
- No values were manually popped from the stack.
- The stack was only used to store the return address.
- After the function returned, `RAX` contained the value 15.
- `RSP` returned to its original value after the function completed.
