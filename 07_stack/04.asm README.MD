# README - 04.asm

```asm
call work
```

calls the `work` function. Since this is a 32-bit program, the return address is pushed onto the stack and `ESP` decreases by 4 bytes.

```asm
push ebp
```

pushes the current value of `EBP` onto the stack. This causes `ESP` to decrease by another 4 bytes.

```asm
mov ebp, esp
```

creates a new stack frame by making `EBP` point to the current top of the stack. This instruction does not change `ESP`.

```asm
sub esp, 8
```

allocates 8 bytes of space on the stack for local variables. `ESP` decreases by 8 bytes.

```asm
mov dword [ebp - 4], 100
mov dword [ebp - 8], 200
```

store the values 100 and 200 in the stack frame. These instructions use the allocated stack space but do not change `ESP`.

While stepping through the program, I observed that the values 100 and 200 were stored at `[ebp-4]` and `[ebp-8]` respectively.

```asm
mov eax, [ebp - 4]
mov ebx, [ebp - 8]
```

load the values from the stack into `EAX` and `EBX`. The stack contents remain unchanged.

```asm
nop
```

does not perform any operation and does not affect the stack or register values.

```asm
mov esp, ebp
```

restores `ESP` to the start of the stack frame and releases the space that was allocated for the local variables.

```asm
pop ebp
```

removes the saved value of `EBP` from the stack and restores it. `ESP` increases by 4 bytes.

```asm
ret
```

removes the return address from the stack and returns execution to `_start`. `ESP` increases by another 4 bytes and returns to the value it had before `call work` was executed.

## Observations

- `call work` pushed the return address onto the stack.
- `push ebp` saved the previous value of `EBP`.
- `sub esp, 8` allocated space for two local variables.
- The values 100 and 200 were stored at `[ebp-4]` and `[ebp-8]`.
- `mov esp, ebp` released the local variable space.
- `pop ebp` restored the previous value of `EBP`.
- `ret` removed the return address from the stack.
- The program uses `ESP` and `EBP` because it is a 32-bit program.
- After the function finished, the stack was restored to its original state.
